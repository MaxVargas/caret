Functors (Mathematics)

22-02-2025

Normally, you learn about functions when encountering set theory. Sets don’t really have structure, so a function doesn’t really need to satisfy much apart from passing the vertical line test1. As one learns more math, it becomes common to care about sets with some extra structure and you’ll want your functions to respect this extra structure. For example, when a student learns about groups, they learn to care about group homomorphisms. Or when they learn of topological spaces, they’ll care about continuous maps. There’s a similar moral with category theory (although a category isn’t “just” a set with extra structure like those previous examples).

Morally, a functor is a function between two categories. That is to say, a (covariant2) functor F:C→D from a category C to another category D is just a way to go from the first category to the second in such a way that the categorical structure gets preserved. Keeping in mind that some of the core data of a category is just its objects and morphisms, F needs a way to send objects of C to objects of D , and similarly for morphisms, satisfying some structural constraints. More precisely, F consists of the data:

  • An assignment FX∈O(D) for each X∈C .
  • An assignment F(g):FX→FY for each g:X→Y∈HomC​(X,Y) .

These assignments have to satisfy the following structural rules:

  • F preserves composition: F(h∘g)=F(h)∘F(g) for each g:X→Y and h∈Y→Z . That is,

F(h∘g):FX→FZ=FXF(g)​FYF(h)​FZ.

  • F preserves identities: F(1X​)=1FX​ for all X∈O(C) .

Now all of a sudden if I want to write down examples of morphisms then we ought to be comfortable with some categories! We can bank off the examples from above.

  • Fix a field F . there’s a functor Forget:Vec→Set which sends a vector space to itself, viewed just as a set. It also sends any linear map to its self-same map, viewed as a map between sets.
  • Continuing with notation from the previous example, there’s a functor Free:Set→Vec which sends a set X to the F -vector space with basis given by elements of X . Elements of Free(X) are (formal) linear combinations of elements of X . A function g:X→Y between sets gets sent to the linear map defined by:

Free(g):Free X→Free Y,x∈X∑​ax​x↦x∈X∑​ax​g(x)

  • Take a graph G and consider C(G) as in the previous section. Given any v∈V , there’s a functor HomC(G)​(v,?) which sends any w∈V to the set HomC(G)​(v,w) , which is definitionally equal to the set of paths v⇝w . To any morphism w⇝w′ , we get a function between sets HomC(G)​(v,w)→HomC(G)​(v,w′) given by appending a path v⇝w with the path w⇝w′ . I’ll note that this is a special case of the more general notion of a representable functor and is related to the Yoneda lemma.
  • If we are given a graph homomorphism f:G→H , then we can build a functor F:C(G)→C(H) in an obvious way. Try to check that the ’obvious’ definition is actually a functor.

An endofunctor is just a functor of the form F:C→C . Here are some examples:

  • Let X be a set and consider the functor X×? which sends any other set Y to the product X×Y and any morphism f:Y→Z to the map (1X​,f):X×Y→X×Z . This is an endofunctor on Set .
  • More generally, in any category where it makes sense to take finite products, you can mimic the above definition.
  • You can compose the functors Free and Forget to get endofunctors Free∘Forget:Vec→Vec and Forget∘Free:Set→Set . For the vast majority of vector spaces, V , Free(Forget V) is likely quite large!
  • Let Vecf​ be the category of finite-dimensional vector spaces over F . Fixing k∈N , there is a functor Symk which sends a vector space V to its k -th symmetric power, Symk V . Similarly, there functor ⋀k which sends V to its k -th exterior power, ⋀kV . I’m not defining the assignment of this functor on morphisms, but if you’re interested then you can look up the definition of the symmetric and exterior powers and then you should be able to piece it together. These functors are examples of polynomial functors.
