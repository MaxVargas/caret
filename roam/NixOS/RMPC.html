Ok I kinda got rmpc (terminal-based music player client) working with youtube downloads. This link was quite useful in debugging my mistakes, with the full nix config here. You’ll be able to find how I handle rmpc, mpd, and any other dependencies, see the rmpc yt docs for more.

It’s not 100% smooth, but it works. To add a song from youtube, run the command 

rpmc addyt <link>

With my setup, it’ll successfully download but then MPD, the music player daemon, will bug out and say the file doesn’t exist. Within rmpc, you can rescan and the song should be visible and playable now.
