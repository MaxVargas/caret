Building Up! The Category of Endofunctors (of C )

At this point, we can convince ourselves that we know what an endofunctor is haha. Now we need to understand how they form a category. We’ve already got the objects (endofunctors, duh), so we just need the morphisms. Such ’arrows’ between functors are called natural transformations and, in the same sense as how functors are structure-preserving maps between categories, these natural transformations are structure-preserving maps between functors. I guess we now have ’arrows between arrows,’ so it might be useful to specify our notation to not get confused. A functor is still an arrow between categories: F:C→D . Given another functor G:C→D (note that these two functors have the same source and targets), a natural transformation α:F⟹G is the data of

  • a morphism αX​:FX→GX for each X∈O(C) .

This data has to satisfy the rule that for any arrow f:X→Y between objects of C , we have an equality of morphisms αY​∘F(f)=G(f)∘αX​ . This is often depicted diagrammatically as saying that the following diagram commutes (traversing the arrows through the top right corner gives the same result as the traversal through the bottom left).

That is, given some function f:X×Y→Z whose inputs are pairs (x,y) , we can define a function fˉ​:X→(Y→Z) by the following definition: x↦(y↦f(x,y)) in other words, fˉ​(x) is a function Y→Z , and fˉ​(x)(y):=f(x,y) . It turns out this map is a bijection, and actually defines a natural transformation between two appropriately defined functors. This turns out to be an isomorphism, which I won’t go into here, but this word ’isomorphism’ tells us that f and fˉ​ are equivalent though the given bijection. Again, intuitively this means that your functions on two variables can be thought of as a cascade of functions of a single variable where you’re just plugging in one variable at a time.1

I consider the last example a special case of the tensor-Hom adjunction.

With a couple examples in hand, now we can define the category of endofunctors (of a given category C ). We’ll denote this category End(C) . The objects here are just functors F:C→C and morphisms are natural transformations α:F⟹G , where F and G are endofunctors of C . The first example above was a morphism in End(Set) .

Monads: Monoids in the Category of Endofunctors

Finally, we get to define the concept of a monad…! First, a clarification. When talking about monoids, I chose to be imprecise about the ’monoidal product’ ⊗ and the ’unit object’ 1 . In general, being able to talk about such things presumes that you have some monoidal category floating around. I’m not going to get into the precise detail here, but luckily the category of endofunctors (on a given category) turns out to be one! All that’s important for now is that there is a monoidal product (i.e., a way to compose functors to satisfy a certain set of conditions) and this monoidal product is just functor composition. Further, the monoidal unit is the identity functor. That is,

F⊗G:=F∘G,1X=X  for all X∈O(C)

In fact, End(C) turns out to be a strict monoidal category, meaning that given three endofunctors F,G and H , we have that (H∘G)∘F=H∘(G∘F) .

Now we can write what it means for a functor M to be a monoid in this category. Going back to the phrase “a monoid in the category of endofunctors”, we just need M to satisfy the monoid axioms. For now, let’s let Id denote the identity endofunctor: IdX=X for all X∈O(C) and you can guess what it does on morphisms. All we’ll need for M to have the structurer of a monad is just some morphisms (i.e. natural transformation) m:M∘M→M and u:Id→M that make those diagrams from Monoids commute, which I’ll copy for this context below. Example 1 This is enough to get us to our first monad — the identity functor! It’s not a very interesting one, but go chase around the definition to verify that it is, indeed, a monoid in the category of endofunctors. In particular, since we have 1∘1=1 , we can take m to be the identity natural transformation: mX​=1X​:(1∘1)(X)→1(X) . The unit morphism is just the identity on 1 .

Example 2: recall the functors Free:Set→Vec and Forget:Vec→Set between the categories of sets and vectorspaces. The functor F:=Forget∘Free:Set→Set turns out to have the structure of a monad! To define the multiplication natural transformation, m:F∘F→F , we need to define maps F(FX)→FX for all sets X . Repzc that elements of FX are linear combinations ∑x∈X​ax​x of elements of X . where we define ba​:=ba​​ . In the last equality, note that we can associate any a​=∑x∈X​ax​x with a uniquely defined function a:X→F by examining the collection of coefficients. This gives a natural way to ’simplify’ elements of F(FX) into elements of FX . That is, it gives us a function m:(F∘F)X→FX for all sets X . This turns out to be a natural transformation. We can define the unit by specifying a map uX​:X→FX for each X . The map is simple in this case, with uX​(x)=x .

Example 3 The power set monad. This one is similar to the last one, but a bit easier. There’s a functor P:Set→Set which takes a set X to its power set PX , which is just the set of subsets of X . This functor sends a function f:X→Y to the function Pf:PX→PY which sends a subset U of X to the subset f(U) of Y . The monad structure on P can be described by defining maps mX​:P(PX)→PX for each set X . Note that elements of P(PX) are sets of subsets of X , so we can simply define mx​:P(PX)→PX,{U⊂X}↦⋃U The unit morphism u:1→P once again can be defined by specifying maps uX​:X→PX that are natural in X . Here, uX​(x)={x} .

Example 4 Consider the category of finite-dimensional vector spaces over a field F , Vecfd​ . Let A be a finite-dimensional F -algebra. Using the tensor product over F , we can construct a monad A⊗?:Vecfd​→Vecfd​ . The multiplication map m:A⊗(A⊗?)→A⊗? can be defined using the usual multiplication on A . That is, for each vector space V , we have a map m:A⊗A⊗V→A⊗V,a⊗a′⊗v↦a⋅a′⊗v The unit map 1→A⊗? can be constructed through observing that there is a natural isomorphism2 between the identity functor and the functor given by tensoring with the base field; 1≃F⊗? . Using this identification, the unit map is defined through the unit map F→A,s↦s⋅1 for A .

Let Rep(Sn​) be the category of finite-dimensional representations of the symmetric group, Sn​ , again assuming some base field F . Let V=Fn be the natural representation of Sn​ .
